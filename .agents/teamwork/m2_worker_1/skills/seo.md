# All-in-One SEO Engine (`/seo`)

Summary of methodology relevant to R2:
- Title Tag: Primary keyword near start, concise (50-60 chars or per project constraints 40-75).
- Meta Description: Compelling, 130-180 chars.
- Headings: Single H1, logical hierarchy (H1 -> H2 -> H3).
- Schema: Follow project guidelines (strict note: project forbids FAQPage schema in JSON-LD).
- Content quality and GEO: citable answers, clear formatting, user-centric guides.
